# FAH-Rojas-Report (legacy)

This repository holds the original static HTML build of **fah.rojasreport.com**, served by GitHub Pages from the `MAIN` branch.

**It is superseded.** The current site is the Next.js app at
`apps/fah` in [HollandHouseHellevoet/RojasReportIntelligence](https://github.com/HollandHouseHellevoet/RojasReportIntelligence),
deployed by Netlify (project `fah-rojasreport`).

Do not edit content here. Once DNS for fah.rojasreport.com is pointed at Netlify,
delete the `CNAME` file in this repo so GitHub Pages releases the domain, then archive the repository.

See `SITES.md` in RojasReportIntelligence for the full map of Rojas Report sites, repos and hosts.
